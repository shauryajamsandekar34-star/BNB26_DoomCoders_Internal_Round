# BNB26 - DoomCoders (Internal Round) 🚀

This repository contains the official codebase developed by **DoomCoders** for the **BNB26 Internal Round**. The project features a full-stack web application incorporating real-time live captions and secure authentication.

---

## 📌 Features

- **User Authentication**: Secure user login and registration powered by **Firebase Authentication**.
- **Roundtable Live Captions**: Real-time automated live captioning MVP functionality.
- **Full-Stack Architecture**: Separated frontend and backend modules for modularity and scalability.
